# Kartvizit Şablonu

HTML ve CSS ile tasarladığım boş kartvizit şablonu. İsteyen indirip kendi bilgileriyle doldurarak kullanabilir.

- Sadece `index.html` ve `style.css`, JavaScript ya da kütüphane yok
- Degrade arka plan, yuvarlak profil fotoğrafı, üzerine gelince hafifçe büyüyen kart
- Küçük ekranlarda kart ve yazılar küçülür

## Nasıl kullanılır?

1. Repoyu indir (**Code → Download ZIP**) ya da klonla.
2. Fotoğrafını aynı klasöre `my photo.jpg` adıyla koy ya da `index.html` içindeki `src` kısmını kendi dosya adınla değiştir.
3. `index.html` içinde ad-soyad, unvan, şehir, LinkedIn, GitHub ve e-posta kısımlarını doldur. Doldurulacak yerlerin yanında açıklama yorumları var.
4. `index.html` dosyasını tarayıcıda aç.

Renkleri değiştirmek istersen `style.css` dosyasındaki arka plan degradesiyle (`linear-gradient`) oynayabilirsin.
